Download once, then use the selected experiment’s environment

Download the computational checkout and extract it into a writable folder. Open a terminal in the extracted folder containing tools and experiments. Alternatively, obtain the pinned computation release with Git:

git clone -c core.autocrlf=false https://github.com/scholarhaozheng/mobility-network-lab.git
cd mobility-network-lab
git checkout reproduction-2026-10-04-r14
git rev-parse HEAD

The website and its instructions are r19. Computation source, inputs and execution receipts remain pinned to r14. Environment commands appear with each record, including Python 3.11 and native-runtime exceptions; a newer documentation release does not mean every solver was rerun.
