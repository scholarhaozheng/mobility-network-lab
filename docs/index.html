Start with a runnable example

Install. Run.
Check the result.

The bundled capacity example starts with raw CSV inputs. Automatic initialization and the existing two-phase solver produce complete path-flow outputs.

Read the installation guide →
python -m pip install -r requirements.txt

python tools/mnl.py run \
  --input app/cases/capacity_zone_probe/input \
  --config app/cases/capacity_zone_probe/case.json \
  --seed-mode auto --seed-k 1 \
  --output results/capacity-demo

python tools/mnl.py verify --run results/capacity-demo

Shell line continuation is shown for readability. The documentation includes single-line commands for Windows, macOS and Linux.
