It is a computational checkout, not the full website. Licenses and third-party notices are included. Python packages and solver binaries are installed separately.

2. Extract, install and check

Download computational-checkout.zip, then run these commands in Windows PowerShell. Use a new destination directory.

if (Test-Path -LiteralPath .\mobility-reproduction) { throw 'Choose a new empty destination.' }
Expand-Archive -LiteralPath .\computational-checkout.zip -DestinationPath .\mobility-reproduction
Set-Location .\mobility-reproduction
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-tested.txt
.\.venv\Scripts\python.exe -B tools/mcl_reproduction_check.py
.\.venv\Scripts\python.exe -B tools/mcl_reproduce.py list

The integrity check is solver-free and uses no network access. It verifies the 200 unique pinned computational and native-environment setup files plus the 41 archived receipts. Passing it does not perform a fresh computation.

Clone the full repository or use another operating system

The compact ZIP is sufficient for the registered computations. For the complete website and project use this tagged repository checkout:

git clone -c core.autocrlf=false https://github.com/scholarhaozheng/mobility-network-lab.git
cd mobility-network-lab
git checkout reproduction-2026-10-04-r14
git rev-parse HEAD

On macOS/Linux, extract the ZIP with unzip, use python3.12 -m venv .venv and .venv/bin/python. Actual numerical validation was on Windows. The native L3 controller is Windows-specific.

3. Select an exact experiment, then run and verify

Choose among the 41 verified recipes. The portal provides each experiment’s environment, input download links, computational source, command, numerical thresholds and receipt. Hong Kong legacy FW and the seven public prepared-input controls use their own Python 3.11 environments (the controls require requirements-reproduction-public-controls.txt, including pandas, in .venv-public-controls); Algorithm B requires the pinned tap-b build; Boston native L3 uses the separate exact environment lock.

A small starting example, using the standard environment:

.\.venv\Scripts\python.exe -B tools/mcl_reproduction_check.py --experiment admm-r2s-public-C1 --environment
.\.venv\Scripts\python.exe -B tools/mcl_reproduce.py run admm-r2s-public-C1 --output results/admm-r2s-public-C1
.\.venv\Scripts\python.exe -B tools/mcl_reproduce.py verify admm-r2s-public-C1 --run results/admm-r2s-public-C1

This is an authored public control, not a Sioux Falls or Boston city experiment. The output folder must be new or empty. Both commands must exit with code 0, and verification.json must report PASS with every numerical check passing. Inputs, outputs, source identities and tolerances are recorded in the result directory.
