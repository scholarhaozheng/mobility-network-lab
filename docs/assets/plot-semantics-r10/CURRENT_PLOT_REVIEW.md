## 先回答：算法错了，还是区域太小？

现有证据不支持把短图统一归为这两个原因。必须分成初始化达门、共享容量不绑定、有效但失败的数值端点，以及本来就只画方法终点四种情形。区域面积尚未做控制实验，不能写成已证实的原因。静态 BPR 中 capacity 是费用曲线的尺度，v/c>1 不等于违反 T4 的硬容量约束。
