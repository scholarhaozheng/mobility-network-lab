Source attribution: https://www.openstreetmap.org/copyright

This archive offers the complete retained derivative used in the published physical-road figure, free of charge. network.csv contains all 14,203 retained physical/turn solver arcs. physical_road_links.csv has all 5,138 directed physical geometries, source OSM IDs and engineering speed/capacity fields. restriction_audit.csv and access.csv retain the model restrictions and zone-to-network association. PHYSICAL_ROAD_FLOW.csv includes all 5,138 assigned physical rows, including zero flow. The exact saved build audit records the transformations. These files are offered under ODbL 1.0; model demand and original software are separate works. No commercial basemap, original GTFS, passenger itinerary or personal movement is included.
