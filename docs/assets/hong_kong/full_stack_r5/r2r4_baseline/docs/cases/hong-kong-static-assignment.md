# Static assignment

The network uses physical BPR arcs, allowed turn arcs and separate origin/destination zone connectors. All free speeds, lanes and capacities are engineering proxies graded by their underlying official evidence. Static FW and official `spartalab/tap-b` Algorithm B were run on identical expanded links and 8,930 positive ODs. The accepted task-local adapter is lossless for this TAPLab-compatible input; official stock-converter parity is not claimed.

The independent evaluator reports a Beckmann objective of 1,676.01213133 for both, maximum physical flow difference below 1e-12 PCE, zero prohibited turns and zero OD imbalance. The 723.191227885 PCE one-hour load is a modeled technical scenario, not an observed traffic forecast. Detailed reports are `phase_b/STATIC_ASSIGNMENT_COMPARISON.json` and the Phase A/B checkpoints.
