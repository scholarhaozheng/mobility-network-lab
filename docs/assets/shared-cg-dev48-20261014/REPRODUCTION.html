git clone https://github.com/scholarhaozheng/mobility-network-lab.git
cd mobility-network-lab
python -m pip install -r examples/shared_cg_dev48_20261014/requirements.txt
python examples/shared_cg_dev48_20261014/run.py --list
python examples/shared_cg_dev48_20261014/run.py --case boston_10_H --output /path/to/new-boston-run
python examples/shared_cg_dev48_20261014/run.py --case boston_10_H --output /path/to/new-boston-run --execute

Choose another case ID from the list below. Without --execute, the entry checks and prepares the case inputs. With it, the code constructs the required intermediate model, runs the case’s actual algorithm branch and its checks. Use a new output directory; the displayed frozen records are references, not files to overwrite. Compare numerical results with the selected saved result and declared tolerances; solver versions and platforms can change roundoff and intermediate iterates. A rerun has its own certificate and does not inherit acceptance merely from the selected historical run.

Population preparation, trip generation, distribution and mode choice retain the existing project workflows. These CG experiments start from their documented parent assignment demand and network. Follow the case input provenance and existing city reproduction pages when rebuilding that earlier chain. Raw provider archives requiring external retrieval are identified by source and version; a current upstream download is not automatically the historical input.

Export and draw a newly computed run

python -m pip install matplotlib==3.7.1 Pillow==9.4.0 fonttools==4.25.0
python tools/visuals/export_cg_run_plot_data.py --run /path/to/new-boston-run --output /path/to/new-boston-plot-inputs
python tools/visuals/render_cg_v1_20261017.py --input-root /path/to/new-boston-plot-inputs --output-root /path/to/new-boston-figures

The exporter reads WORKSPACE_INDEX.json and the matching NEW_RUN.json execution binding, checks configuration and certificate hashes, and replays actual saved paths and flows, checks demand, capacity and path costs, and binds the actual-run primal and available lower-bound certificates. It reuses only the same-case map geometry. Historical flows, objective values and certificates are never substituted. A prepared workspace without solver output or a passing primal certificate is rejected; an absent same-run lower bound remains unavailable. All generated files stay outside the website checkout.

Exporting and drawing saved outputs do not run optimization or full-graph pricing. They do not issue a new optimality certificate; those claims depend on the actual run’s separate verifiers. New runs can have different histories and must retain their own results and status.

Reproduce the displayed figures from their plot data

python -m pip install matplotlib==3.7.1 Pillow==9.4.0 fonttools==4.25.0
python tools/visuals/render_cg_v1_20261017.py --output-root /path/to/new-v1-figures --redraw-maps

The full repository checkout supplies the displayed plot data and style helpers. Add --cases boston_10_H to select cases. This plotting command does not run optimization or pricing. The current movement map has one canonical plot-data record per run; old duplicate maps and duplicate geometry records are omitted.

The three cards show capacity-resource slack and path-pool growth (or the actual seed/exact feasibility construction), the real objective with signed difference to the fixed same-run final lower bound, and final integrated physical-link movement flow. The optional diagnostic view shows current and best saved per-round bounds separately. The fixed-reference difference is not a per-round pricing gap. Missing bounds and unrecorded histories remain missing.

All visible SVG/PNG exports and direct Plot data links refer to the selected actual run. The map and curve values have not been changed by source/input packaging. Constant or one-state records are not expanded into invented iterations.
