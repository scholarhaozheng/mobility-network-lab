## 3. 必须坚持的科学解释

| 事项 | 正确读法 | 不可采用的读法 |
|---|---|---|
| 一致性 | 同用途、匹配实例、相同指标意义与正确单位，再对齐样式 | “都用了相同字体/蓝色，所以已经一样” |
| 静态方法图 | 该方法自身完整物理向量＋地图＋全路段含0的分布 | 借几乎相同的方法流量；用目标柱或维数柱冒充空间分配 |
| 端点与轨迹 | 端点地图、类别柱、门限检查是合法的不同证据 | 按条形数/连线数推断迭代数，或把端点说成收敛过程 |
| 显示下限 | 原数值不变；精确0或小于下限的值只作明确视觉处理 | 把显示floor当真实残差，或为了画对数图制造正数 |
| 拥挤性能 | 当前无绑定容量的实例说明该场景达到固定门槛 | 直接推出算法普遍更快、城市太小或算法有错 |
| 容差 | 达到事先冻结的数值门槛 | 精确数学最优、无限精度证明 |
| 缺失数据 | 标记“未保存”“没有实际发生”或“尚未确认映射”，区别说明 | 以总量拆逐OD；插值出迭代/恢复；将null、Exhausted当0 |
| 实例比较 | 同一需求、路网、容量、时段、路径/commodity范围内解释 | 把全城市、S72/S20、T4、HK10/HK4拼成同一实验 |
| 方法状态 | CG、Native、LR、ADMM、LP各看自己的证书 | 某方法成功则全城所有方法成功；外部可行见证当LR own UB |
